# Hadrius

<p>Hadrius is an all-in-one RegTech platform that automates SEC and FINRA compliance for financial firms. It is built to scale with the growing needs of firms and engineered for security from day one.

<p>Our services include:
<ul>
  <li>Transactional Surveillance — Monitoring of client and employee transactional activity</li>
  <li>Communications & Marketing Review and Archiving — Supervision, review, and approval workflows for websites, digital comms and marketing content</li>
  <li>Employee & Firm Oversight — Attestations, certifications, approvals, audits and vendor oversight</li>
  <li>Filings — FINRA Gateway API integrations for U4/U5, licensing & registration, Form BR, and CE tracking</li>

</ul>
